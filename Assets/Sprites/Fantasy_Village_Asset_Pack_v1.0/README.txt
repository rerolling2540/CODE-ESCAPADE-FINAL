FANTASY VILLAGE ASSET PACK
Version 1.0


ABOUT

A pixel art asset pack for creating cozy fantasy and medieval village environments.


CONTENTS

BUILDINGS
- 3 houses
- 1 tavern
- Front views
- Back views


FURNITURE
- Beds
- Tables
- Chairs and stools
- Benches
- Wardrobes and cabinets
- Rugs
- Other furniture variations


PROPS
- Barrels
- Sacks
- Books and book stacks
- Chests
- Various small props


FORMAT

- PNG
- Transparent background
- Pixel art
- Designed around a 16x16 px base grid
- Larger assets may occupy multiple 16x16 tiles
- Assets are provided as spritesheets


FOLDER STRUCTURE

Buildings/Front
Buildings/Back
Furniture
Props
Preview

The Preview folder contains showcase images and is not intended
to be used as a spritesheet.
